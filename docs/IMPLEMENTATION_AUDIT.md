## 4. 本轮要求的十项静态审查回答

### 4.3 `coordination_metrics()` 在什么位置被调用

- 在 `ui_v3.py` 的 `build_html_report()`、`render_plans()`、`render_coordination()` 中被调用，用于页面展示、报告生成和代表方案复核。[静态代码已确认][尚未运行验证]
- 证据：`ui_v3.py` 中 412、659、669 行附近调用。

### 4.4 `coordination_metrics()` 是否参与精确枚举的目标函数

- 不参与。[静态代码已确认][尚未运行验证]
- 证据：`solve_exact()` 内部只调用 `evaluate_unit()`、`evaluate_region()`、`check_plan_constraints()`，未调用 `coordination_metrics()`。

### 4.5 `coordination_metrics()` 是否参与 NSGA-II 个体评价

- 证据：`solve_nsga2()` 的内部 `evaluate()` 只调用 `evaluate_unit()`、`evaluate_region()`、`check_plan_constraints()`，未调用 `coordination_metrics()`。

### 4.6 当前区域协同是否会改变 Pareto 支配关系

- 不会。[静态代码已确认][尚未运行验证]
- 原因：Pareto 判定只基于 `evaluate_region()` 产出的四目标列，而该函数未接收 `coordination_metrics()` 的结果。

### 4.7 地图风险路径数据和韧性评价的路径数据是否来自同一数据源

- 不是同一数据源。[静态代码已确认][尚未运行验证]
- 地图风险路径与空间协同页面使用 `st.session_state.topology.paths`。
- 韧性中的路径覆盖使用 `unit.key_paths` 与 `measure.covered_paths`。

### 4.8 当前区域协同页面是在解释既有结果，还是首次计算新结果

- 当前页面是在基于既有代表方案 `details` 首次计算新的协同解释指标，而不是读取已在优化链中固化的协同结果快照。[静态代码已确认][尚未运行验证]
- 这说明它更像“展示层二次分析”，不是“优化链内协同结果回显”。

### 4.9 如果只调整页面顺序而不修改评价函数，为什么不能解决问题

- 因为页面顺序只改变前端展示时序，不改变后台 `solve_exact()` 和 `solve_nsga2()` 内部的目标函数计算顺序。[静态代码已确认][尚未运行验证]
- 若后台仍未调用区域协同聚合，Pareto 支配关系仍然只基于未协同的四目标值。
- 因此，只做页面调序不能让区域协同参与优化，只会制造“看起来提前了、实际上没提前”的表达风险。

## 5. 为什么“区域协同未进入优化链”是关键缺陷

- [静态代码已确认][尚未运行验证] 正式方法要求先完成风险路径分析和区域协同聚合，再形成村域候选方案四目标并进入 Pareto 搜索。
- [静态代码已确认][尚未运行验证] V3 当前是先用 `evaluate_region()` 形成四目标并完成 Pareto 搜索，再在页面层用 `coordination_metrics()` 做解释。
- 影响：
  - 区域协同无法参与非支配判断；
  - 关键路径覆盖差的方案可能错误保留；
  - 协同更好的方案可能无法因协同优势进入 Pareto 前沿；
  - 页面中的“协同最优/薄弱环节”与求解器真实排序依据发生分裂。

## 6. MATLAB 与 V3 的边界结论

- [静态代码已确认][尚未运行验证] MATLAB当前主流程实际启用的是 DTLZ2 三目标标准测试函数；ZDT 相关内容主要存在于注释代码或标准函数验证内容中。标准测试函数只能说明 NSGA-II 算法框架具备基本验证基础，不能证明正式工程四目标模型已经接入，也不能证明工程问题已经完成收敛性验证。
- [正式材料声称但当前代码证据不完整] 科技报告称完成了 ZDT1 双目标测试函数和 DTLZ2 三目标测试函数验证；当前归档 MATLAB 代码中，可直接追溯的主流程主要是 DTLZ2，对 ZDT1 尚缺乏与 DTLZ2 同等完整的主流程可复现证据。
- [静态代码已确认][尚未运行验证] V3 比 MATLAB 更接近科技报告流程，但在“区域协同进入优化”与“路径数据源统一”两个关键点上仍未达标。
- [静态代码已确认][尚未运行验证] MATLAB 注释中的 `A-G`、`omega`、`FS` 公式当前只能保留为历史算法试验材料说明，不能作为 V4 正式工程评价依据。
