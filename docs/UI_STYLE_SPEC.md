# V4 界面风格简要基线

## 1. 适用范围

本文件仅用于沉淀 V4 后续界面设计的简要参考，不改变正式业务流程和计算方法。

参考来源：

- 图片1：`references_private/reference_ui/图片1.png`
- 图片2：`references_private/reference_ui/图片2.png`

两张图片已成功读取。[静态参考已确认]

## 2. 总体视觉方向

- 以图片1的现代化深蓝、藏青色科研平台风格为主。
- 以图片2的地图功能布局与专业工作台组织方式为辅。
- 视觉气质定位为：正式、现代、简洁、科研平台化。
- 不做像素级复刻，不照搬原平台名称、业务文字、数据和无关功能。
- 截图无法确认的色值、字体、尺寸、阴影和间距均标记为 [暂定]。

## 3. 页面基本框架

### 3.1 地图类页面

- 推荐采用“中央大地图 + 左侧控制区 + 右侧详情/图层区”的三栏工作台。
- 顶部保留平台标题和一级导航。
- 地图尽量占据主视觉区域，避免被大面积说明文字压缩。

### 3.2 非地图主导页面

- 参数配置、优化计算、Pareto 分析、算法验证等页面不必强行全屏地图。
- 可采用“左侧参数配置 + 中央主内容 + 右侧辅助结果卡片”或“上部图表 + 下部表格”的分析布局。

## 4. 顶部导航

- 顶部一级导航建议固定在页面上方。
- 标题区建议使用深蓝/藏青底色，体现科研平台统一感。
- 一级模块名称应正式中文表达，不出现 Demo、MVP、原型 等措辞。

## 5. 左侧导航或控制区

- 左侧适合承载：
  - 模块导航；
  - 参数配置；
  - 求解方式选择；
  - 运行按钮；
  - 过滤条件。
- 风格上参考图片2的专业控制台结构，但视觉语言更接近图片1的深色卡片化处理。

## 6. 中央业务区

- 地图页：中央为主地图、路径、图例、比例尺与必要地图工具。
- 非地图页：中央为 Pareto 图、评估图表、分析结论、结果表格等核心内容。
- 中央区应保持最高信息权重，不建议被过多装饰性边框切碎。

## 7. 右侧详情或图层区

- 右侧适合承载：
  - 图层控制；
  - 单元详情；
  - 方案摘要；
  - 风险提示；
  - 数据查询面板。
- 风格上建议采用独立深色卡片或浅深对比面板，强调辅助信息层级。

## 8. 组件风格建议

### 8.1 地图

- 地图是空间类页面的核心区域。
- 推荐保留专业地图工具、图例和比例尺。
- 路径、风险区、治理单元等图层应具备明确层级，不宜全部同色。

### 8.2 卡片

- 采用较简洁的圆角卡片或面板。
- 统计卡片宜信息密度高，但不宜使用夸张渐变或娱乐化图形。

### 8.3 按钮

- 主按钮建议使用蓝青系强调色。
- 警示、风险或删除类操作使用橙色或红色强调。
- 次级按钮保持低饱和、低干扰。

### 8.4 表格

- 表格应偏科研平台风格，重可读性与密度。
- 推荐清晰表头、适度分隔线、必要行高亮，不做花哨装饰。

### 8.5 图表

- 图表应配合正式中文标题、坐标和图例。
- 颜色体系需与整体平台保持一致，不随机换色。

## 9. 风险与状态颜色

- 主色方向：[暂定] 深蓝、藏青。
- 强调色方向：[暂定] 青色、蓝色、橙色。
- 风险类颜色：[暂定] 低风险用蓝青或绿色，中高风险逐步转向橙红。
- 状态类颜色：
  - 成功/有效：绿色系；
  - 提示/待处理：蓝青系；
  - 警示/待复核：橙色系；
  - 错误/不可行：红色系。

## 10. 各类业务页面的适配布局

- 项目总览：顶部概况 + 中央摘要卡片 + 辅助地图或关键指标。
- 治理单元与空间拓扑识别：中央大地图 + 左右辅助面板。
- 工程措施库与适用性准入筛选：左侧筛选条件 + 中央表格/矩阵 + 右侧详情。
- 评价参数与约束配置：以控制区和参数表为主，不强求大地图。
- 多目标优化计算：以参数、进度、结果摘要和计算状态为主。
- Pareto方案与村域协同结果解析：中央 Pareto 图和协同结果图，配合右侧方案摘要。
- 方案复核与成果导出：以清单、报告摘要和导出操作为主。

## 11. 计算引擎与界面关系

- 界面风格统一不得改变正式业务流程和计算方法。
- 后续统一界面不得导致计算引擎重写。
- 页面层不得自行计算或拼装另一套目标值。
- 当前只有两张参考截图，尚不能确定最终接入方式；后续可根据平台技术条件采用独立运行、iframe 嵌入或原生模块接入。[暂定]
