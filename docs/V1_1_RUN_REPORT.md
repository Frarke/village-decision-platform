# V1.1 输入交付与真实地图改进报告

日期：2026-09-15。基线提交：13403cb。沿用原研究材料和已确认四目标公式，没有修改正式权重、措施参数数值或references_private。

## 1. 针对本轮反馈完成的改进

原V1虽然确实进行了像元连通计算，但四个矩形高值片区的模拟输入把结果过度限定成方块；白底图、文字措施和按U01输入权重/路径，也没有形成清晰的集成交付。此次补齐以下内容：

- 业务资料清单：明确前序评价、工程调查、项目预算与模型配置分别由谁提供、用于什么、哪些不能互相替代。详见`INTEGRATION_DATA_GUIDE.md`。
- 分文件输入：ZIP内分别保存真实GeoTIFF、研究范围GeoJSON、工程调查CSV、空间权重与路径、预算配置。无需用户填写程序JSON或预先确定治理单元。
- 一次计算：`POST /optimize-package`组装同一请求、运行原评价器/求解器；`view=html`返回可嵌入的完整结果。`/integration`提供“上传资料＋预算＋计算＋结果”独立入口，不依赖Streamlit。
- 坐标绑定：显式权重点和三环节路径坐标自动关联生成单元；不再必须按U01提供信息。数值仍为显式输入，不新增未经确认的权重或自动路径公式。
- 过程地图：已有评价→重点区域→治理单元→工程措施四阶段切换，可查看原值、判定原因和来源像元；规则参数来自本次配置。
- 工程结果：真实影像/地理底图、八类工程立体示意符号、措施点击、方案切换及措施点GeoJSON。宿主可直接复用SVG及符号索引。

## 2. 当前输入与输出

业务用户操作：选择项目范围/资料包，填写预算，点击计算。后台需要研究范围、已有风险/危险性、地形和距离、工程调查、显式权重/路径及配置。易发性/易损性是已有上游成果，可用于图层查看和属性统计；只有这两张图不足以完成现有工程评价。

输出包括生成重点区域、治理单元、来源像元、五类代表方案、完整非劣集、单元措施及指标、措施配置示意点、图标和可嵌入地图。JSON接口字段及资料责任见清单，不要求宿主了解NSGA-II内部过程。

## 3. 真实地点与模拟数据边界

采用已实查的福建培田村位置：116.6346480、25.6390104，来源`https://www.openstreetmap.org/node/8199467914`。记录存于`data/v1_1/location_source.json`。在线影像来自Esri，地理底图来自OpenStreetMap，保留署名。

研究范围是程序设定的演示范围，不是法定村界。48×48评价场、工程调查、风险权重点和三环节路径均为模拟。图层有CRS并在该真实地点上运算，但不是当地风险调查结果；真实底图不等于真实评价数据。未将影像冒充DEM，也未声称完成真实地形三维计算。

## 4. 治理单元怎样实际形成

输入2,304个40米像元；裁剪后1,911个在研究范围内。沿用风险≥3、距承灾体≤100米等报告规则，273个像元进入重点区域，面积43.68公顷。同一调查属性区内共边连通、按1,600平方米最小面积过滤，实际形成4个不规则单元。

输入不含治理单元几何或编号。测试将一个调查区的风险/距离改为不命中规则后，单元数从4变为3；并检验面积减少。另修复不规则研究边界裁剪产生约1e-19平方米浮点碎片的零面积问题，单面与多面使用相同的1e-6平方米数值容差。

## 5. 实际求解结果

精确枚举4,356种组合，575可行、17非劣。种群60、25代的NSGA-II（第二代非支配排序遗传算法，用于搜索多目标非劣方案）实际运行如下：

|种子|唯一方案评价|非劣方案|精确非劣配置覆盖|漏解|
|---:|---:|---:|---:|---:|
|42|1,810|17|100%|0|
|123|1,762|17|100%|0|
|2026|1,827|17|100%|0|

默认560万元预算下，综合均衡成本462.6万元；经济优先323.5万元。结果仅对当前模拟数据和参数成立，不能外推真实工程或大规模最优性。完整数据在`output/v1_1/solver_comparison.csv`、`validation.json`等。

## 8. 尚存问题及待确认内容

1. 当前单元是风险重点斑块与调查分区的结果，尚不是依据真实DEM、坡向、沟谷和滑坡边界形成的地貌/工程单元。
2. 费用仍按单元整套估计，未按挡墙长度、桩长桩数、排水沟长度等工程量计价。细分单元会影响预算，不能把空间分区精细化和工程计价割裂。
3. 目前求解单元内的技术组合；图标采用单元内部代表点，明确`is_design_location=false`。没有精确施工轴线、尺寸、数量及设计安全验算，图标数不是工程量。
4. 权重数值和风险路径仍需显式调查/研究成果；无依据的自动权重、DEM水文路径推断未实现。
5. 易发/易损性到FS0、Krain及措施效应之间没有擅自补造公式；工程效应、成本、组合折减和评分映射仍待标定。
6. 真实底图需网络，离线时仍能显示空间成果和符号；没有缓存地图瓦片。当前栅格需同网格，上游需完成对齐。API仍为同步本地服务，鉴权、作业队列和资源扩展由生产集成阶段处理。
