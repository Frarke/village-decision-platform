# V1 实施计划与验收标准

状态：2026-09-15 完成实施前审计与设计，依用户授权直接实施，不等待额外确认。

- 保留：原 `model/screening.py`、`tagging.py`、`combinations.py`、`pareto.py`、`recommendation.py`、标准函数及原始私有资料、历史 `sample_output`。
- 最小修改：`schemas.py`（校验和集中参数）、`evaluation.py`（读集中参数）、`regional.py`（统一入口完整约束及路径数据）、`solver.py/nsga2.py/workflow.py`（标识与空输入校验）、`ui_v3.py`（拓扑失效标识）、`run_demo.py`（显式路径）、依赖和启动说明。
- 新增：空间适配、识别/连通单元和属性统计、独立服务、空间结果导出/地图图表、HTTP API、正式页面、模拟空间评价输入、运行脚本、业务/API/空间/交互测试、本轮输出目录。

## 实施顺序

1. 固化审计和系统设计；检查可用环境，安装必要 GIS/API 依赖。
2. 输入与空间预处理：格式、CRS、值域、几何/重叠检查；连续重点区域，过滤/拆分，自动属性，显式权重与路径绑定。
3. 修复统一评价入口的约束及路径一致性；保持已有有效公式和搜索机制。
4. 服务装配、完整空间输出和接口；创建与真实接口一致的 MOCK 评价片区数据。
5. 实际跑通四单元；精确与 NSGA-II 对照；留下完整结果与指标。
6. 正式地图页、五方案切换、单元详情、图表、调试模式、离线成果包。
7. 执行相关测试、完整 pytest、Python语法/导入、Streamlit/API启动和关键交互检查；审查 git diff；更新运行报告。

## 测试顺序及完成标准

1. 空间：有效矢量/栅格、投影/裁剪、NoData、重叠/非法几何/无CRS拒绝、阈值边界、连通/过滤/拆分、属性与面积、确定编号、空重点区域。
2. 业务：候选措施、非法组合、统一评价器、预算/安全、显式权重、路径一致性、拓扑改变标识。
3. 小规模：相同候选编码和四目标，精确非劣判定，固定种子复现，近似/完全覆盖与被支配比例如实输出。
4. API：health、prepare、optimize、错误422、导出 JSON 可解析；不把待标定信息丢掉。
5. 正式页面：输入读取、真实运行、五类切换同步、地图事件、KPI/雷达/Pareto/组成、失效结果隐藏、成果包完整。
6. 完整回归和启动；输出目录内保留请求、结果、单元GeoJSON、代表地图、非劣集、对照指标和日志；`docs/V1_RUN_REPORT.md` 给出25项交付问题的明确回答。

最低成功标准：空间评价输入→自动重点区域/单元→属性→原措施/编码→统一四目标与区域协同→实际NSGA-II→非劣/代表方案→可查看可切换的空间治理地图。科研暂定值和实际工程成果严格区分；未完成的核验如实记录。
