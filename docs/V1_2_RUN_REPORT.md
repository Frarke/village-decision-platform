日期：2026-09-15。当前独立入口：http://127.0.0.1:8017/integration 。工作台：http://127.0.0.1:8517/ 。

## 本轮处理的问题

|用户反馈|本轮实现|
|---|---|
|输入资料混乱，需要逐项状态、内置模板和替换校验|9项必需资料、2项可选评价逐项显示；自动载入内置模拟资料；每项可替换、移除、恢复及下载模板。红绿状态区分缺失/错误与通过，整组关联校验通过后才计算。|
|等待界面像在向用户提问|改为准备、校验、正在求解、完成、未完成等实际状态；运行期间锁定输入，无固定假进度。|
|看不出加措施有什么改善|区域四目标同时显示无措施基线、治理后分值及变化；单元安全性/韧性地图支持前、后、变化三种视图；经济性下降照实显示。|
|多个措施图标挤在一起|改为每单元一个紧凑符号组；缩放后屏幕空间避让，必要时用引线连接归属；极密集时归组展开；详细工程示意只在选中面板展开。|
|四个图层的设置和成果含义不清楚|最终入口为“治理方案”“治理成效”“计算溯源”。已有评价是输入，重点区域与单元是中间成果，放入溯源下级选择。|
|右侧反复出现输入输出说明|移除固定“输入与输出的区别”；按当前方案、成效、评价、重点区域、单元来源显示相关内容。|
|图例与地图不对应|地图与措施图例复用同一个SVG；评价分级、成效分级与图例使用同组边界，前后评分保持同尺度；缺少可选评价用灰色。|
|其他细节|替换/预算变化立即使旧结果失效；延迟响应有版本校验；预算输入防抖；完成后自动展开地图，仍可编辑资料；键盘可访问的单元名称；适配窄窗口；JSON错误以中文标明行列。|

## 输入、输出与集成

必需文件：project.json、boundary.geojson、risk.tif、haz.tif、slope_deg.tif、distance_m.tif、profile_id.tif、engineering_profiles.csv、decision_context.geojson。可选文件：susceptibility.tif、vulnerability.tif。内置八类工程措施库单独声明为支持资料，效应与成本待标定。

新增 `GET /input-defaults`、`POST /validate-files`、`POST /optimize-files`。校验和求解均接收调用方的完整文件快照，不维护共享服务器草稿。输入检查涵盖扩展名、编码、JSON/GeoJSON结构、调查表必填列/唯一编号/类型、GeoTIFF单波段/CRS/范围/值域，以及实际生成单元后的工程条件、权重、路径和配置关联。关联校验失败会把相关资料标为待修正，不猜测哪个文件应被自动替代。

`/optimize-files` 返回机器结果 `result` 与可嵌入的 `html`；原 ZIP 和直接 JSON 接口保持兼容。紧凑符号可通过 `/symbols/M01.svg?variant=map` 获取，成果包增加 `symbols/map/`，保留原详细示意图。

文件替换只影响当前页面；刷新恢复内置资料，页面已明确提示。宿主的项目持久化由对接平台管理。内置模拟文件未换齐时不能仅通过修改 project.json 把项目声明成真实资料。

## 成效口径及实际结果

治理前为同一输入与同一评价器下的“无措施”方案。治理后读取所选方案已有目标值；变化为二者分差。没有增加目标、改变权重/阈值/工程公式，也没有生成治理后风险概率。

默认模拟资料，预算560万元，综合均衡方案：

|指标|治理前|治理后|变化|
|---|---:|---:|---:|
|安全性|11.21|67.077429|+55.867429|
|经济性|100|64.571429|-35.428571|
|可持续性|45|63.5|+18.5|
|韧性|25.5|70.297619|+44.797619|

全寿命成本462.6万元，关键路径完整覆盖率66.666667%。实际识别4个单元，重点像元273个、重点面积43.68公顷。区域分值包含风险权重和协同聚合，不能与单元分值简单平均混同。

浏览器实测将项目文件替换为预算400万元后，综合方案成本变为339.2万元；切到经济优先为323.5万元。证明替换文件实际进入求解，并非只更改文件名或展示数字。

## 尚存问题与推荐下一步

1. 当前仍为真实地理位置上的模拟评价、调查、范围和人工路径；效果、费用、安全映射及相关参数待工程标定。分值提高不能解释成实测风险降低百分比。
2. 治理单元为当前规则生成的重点斑块，不是地貌坡单元或设计确认边界。图标只表达技术归属，没有准确挡墙轴线、桩位、工程量或施工顺序。
3. 成本仍按单元措施组合估算，单元拆分可能影响费用。建议下一阶段优先对接一套完整真实调查/地形资料，再明确工程量计算及措施效应标定，避免继续用界面精细程度替代工程精度。
4. 正式上线仍需宿主项目存储、鉴权、异步作业和适合目标规模的GIS处理；这些不属于本轮界面与输入校验改进。

本轮无新增科研公式待确认；上述既有待标定和研究方法缺口继续保留，不自行替用户定案。
