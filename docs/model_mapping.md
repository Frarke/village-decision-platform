# 原始材料与第三版实现映射

## 材料定位

《02_科技报告》是治理单元、8类措施、准入规则、四目标与区域评价框架的主要依据。`01_MATLAB原始代码`主要提供NSGA-II程序结构、DTLZ2标准函数和参数试验参考；MATLAB文件没有实现科技报告中的完整村庄工程模型。

第三版没有修改两份原始材料，也没有把MATLAB的DTLZ2结果包装成工程方案。平台中的离散NSGA-II直接调用Python工程评价、准入与硬约束函数。

## 参数边界

科技报告没有给出全部措施效应、成本、评分映射和阈值的最终标定值。第三版将这些项目标为“待标定参数”或“示例参数”，并允许在措施库和参数配置中修改。平台结果不能直接代替现场勘察、工程设计、施工图或预算。

## 后续工程化
