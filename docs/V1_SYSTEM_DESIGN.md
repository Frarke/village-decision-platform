## 2. 主要断点与冲突

|问题|影响|本轮处理|
|---|---|---|
|从已划单元起步|缺失研究边界中的识别与划分|新增空间适配、重点区域、连续斑块及属性提取|
|无独立服务接口|外部平台需理解前端会话|新增无 Streamlit 依赖的服务与 HTTP API|
|四目标虽已共用，但直接评价缺少准入/组合校验|绕过候选生成可评非法方案|在权威评价入口校验，不静默修复|
|风险权重全零时偷偷均分|违反显式权重要求|校验有限非负且总和大于零|
|单元路径计数来自字段，村域来自 topology|局部展示与优化可能不一致|权威入口用 topology 同步单元路径信息|
|输入散列不包含路径|修改路径可能仍展示旧结果|将 topology 纳入标识|
|README、STATUS、部分旧模型文档、assumptions A19 描述旧经济性与后置协同|与确认方法及代码冲突|当前说明纠正；历史证据标明版本，不改正式公式|
|多措施折减、额外协同、FS映射等仍为示例规则|不能表达为标定结论|集中参数并导出当前值与状态|

正式研究材料没有完整规定空间分割算法、自动风险权重、自动关键路径。不得把连通分割当作正式地貌划分方法，不自动编造权重或路径；下述空间细则为 V1 暂定实现。

## 3. 系统边界、业务流程和数据流

外部空间评价成果 + 村界 + 工程调查属性 + 显式风险权重 + 路径 + 配置 → 空间适配与校验 → 村界裁剪 → 重点区域识别 → 连续斑块/工程属性分界 → 小斑块过滤/可选拆分 → 单元属性提取 → 原措施筛选和组合 → 原统一评价器（含区域协同） → 原搜索器 → Pareto（帕累托非劣：无法在不降低其他目标的同时提高某一目标）集 → 五类代表方案 → 空间结果、图表与完整导出。

本模块不重建上游易发性或风险模型，不把图像当 GIS，不自动反演 FS0、施工空间、滑面、锚固条件。工程调查信息由输入提供；缺失时返回具体字段错误。可运行示例明确标为 MOCK，真实输入不能偷偷回落到示例。

## 4. 输入规范和 GIS 处理

统一请求：`schema_version`, `village`, `spatial_layers`, `engineering_profiles`, `unit_risk_weights`, `topology`, `configuration`，可选 `measures`。

- `village`：id、name、data_status（MOCK/REAL）、source、边界 geometry、CRS。
- 空间适配层统一为非重叠面评价片区：feature_id、geometry、risk（1～5）、haz（1～5）、distance_m、slope_deg、susceptibility（0～1，可选）、vulnerability（0～1，可选）、profile_id；可选 identified_or_risk_area、focus_unit。
- 第一版支持 GeoJSON/带 CRS 的 vector 对象、统一网格数值数组、多波段 GeoTIFF（波段字段映射、NoData、CRS、仿射变换）。本地文件适配提供 CSV/WKT；普通图片返回不支持原因。Shapefile 等以后可增加适配器，不进入 evaluator。
- 单一矢量图层应为上游已叠置的基础评价片区；栅格各字段必须同网格，拒绝错位，不偷偷重采样。分辨率、重采样和分类断点由上游负责。
- 使用真实 CRS 转换，米制投影完成面积/邻近计算，输出统一 WGS84 GeoJSON；检查几何有效、空面、重叠、重复编号、有限数值、范围、缺失字段及村界。保留坐标转换和裁剪统计。
- 工程属性以 profile_id 连接显式调查属性，避免逐像元重复几十个工程字段；不要求提前划定治理单元。profile_id 仅代表属性区，不能取代连通识别。

## 5. 重点治理区域与单元

识别规则依据科技报告表5-1：`risk >= 3 OR distance_m <= 100 OR identified_or_risk_area OR focus_unit`。易发性/易损性统计用于解释，不另外编造四目标或未经确认的组合阈值。

同一工程属性区内，共边的重点面合并为基本单元；角点接触不合并。可配置邻近距离（默认0米）；开启时允许同单元包含间隔面，但不以缓冲区虚增治理面积。不同 profile_id 不合并，以免平均施工条件。按最小面积过滤，可选网格拆分大斑块；按属性区与空间位置排序编号 U01…，原始 feature_id 完整保留。拆分后重新统计属性，过滤损失面积回显。无重点区域返回可解释的空结果，不制造治理需求。

## 6. 属性提取与权重

面积与面积加权平均易发性、易损性、坡度；最大易发性、坡度、风险、危险性；最小承灾体距离；质心；来源片区编号。措施筛选使用最大坡度、最大风险/危险性、最小距离和原工程调查属性。上述统计选择是保守的 V1 暂定规则，需工程复核。

工程属性只保留原 `GovernanceUnit` 真正使用的降雨、坡高、汇水、沟谷、坡脚空间、FS0、Krain、排水/锚固/施工/滑面等条件。自动字段不得被调查属性覆盖。风险权重使用 `unit_risk_weights` 显式键值：先 `/prepare` 获取稳定编号，再提交权重也可；样例一次请求已含四单元权重。不是从风险×面积生成权重。路径也显式输入生成后的单元编号；缺失拓扑与已确认无路径明确区分。

## 7. 原方法复用：措施、编码、四目标、协同、搜索

原8类措施库和准入条件保留；每个基因为该单元合法措施组合索引，同一单元允许最多配置指定数量措施。原互斥及主控规则保留。两搜索器都调用同一权威评价入口，并明确校验非法组合。

四目标保持 METHOD_SPEC：安全 `0.6SFS+0.4S_chain`，经济 `LCI/SC`，可持续 `0.4Seco+0.4Scarbon+0.2Sdisturb`，韧性 `0.5Sredundancy+0.3Srecover+0.2Scoverage`，均0～100且越大越好。货币成本按单元求和，仅用于预算和输出。保留当前临时多措施规则但集中配置、标明待标定，不擅自改正式系数。

区域安全按 `0.6min+0.4风险加权平均`；经济和可持续风险加权；路径覆盖在评价中进入村域韧性。单元展示、路径图和村域评价读取同一 topology。无关键路径的100分延用已记录暂定约定，必须给出提示，不能把未提供路径当作已确认无路径。

精确枚举完整遍历并守护规模上限。NSGA-II（第二代非支配排序遗传算法，用于近似搜索多目标非劣方案）保留现有离散交叉、变异、约束支配、外部修复、拥挤距离、精英与固定种子。只呈现实算历史，不宣称达到理论收敛。小样例运行两者并比较同方案四目标、约束和非劣覆盖。

## 8. 代表方案与结果规范

复用现有确定性规则：安全、经济、韧性、可持续各自指标优先并稳定打破并列；综合均衡使用非劣集内归一化后到理想点的偏好加权距离。多个偏好可能落在同一方案，保留事实。

响应：`recommended_solution`, `representative_solutions`, `pareto_front`, `governance_units`, `priority_areas`, `map_result`, `summary`, `metrics`, `provenance`。每个代表方案带完整单元评价、措施、geometry、前后安全/韧性变化、成本、路径状态、选择依据。完整 Pareto 集保留可复算措施编码。

## 9. API、页面和导出

`GET /health`，`POST /prepare`，`POST /optimize`，FastAPI 自动接口说明。服务不依赖 Streamlit session，配置错误422，计算无可行方案给出约束原因，未知异常记录日志而非吞掉。请求不读取任意服务器路径；文件上传内容先适配再进入模型。第一版为有规模上限的同步本地服务。

正式入口 `v1_app.py`：输入→运行→结果，主图为可点击面单元和村界；五类代表方案切换同步地图、KPI、单元详情；配措施图例、雷达、Pareto投影、措施组成，导出 JSON/GeoJSON/CSV/ZIP 与可离线打开的交互 HTML 地图。页面使用正式中文；数据性质显示“模拟示例数据”，原始数据/接口保留 MOCK 标记。

调试模式展示来源、单元、候选、完整 Pareto、参数和实际历史。原 `app.py/ui_v3.py` 保留为历史开发工作台和回退入口。

## 10. 假设、待标定与替换点

新增待标定项集中在空间配置；已有数值映射、组合增益、成本修正集中到评价参数对象。默认值保持基线，不擅自改变正式指标。工程量不由面积偷偷换算：原措施成本仍按每单元整套估算，细分单元会影响费用，结果必须提示。没有真实标定数据，完整软件闭环不能声称真实工程验证完成。

可替换：空间格式适配、斑块分割/地貌分区、空间统计、调查参数来源、权重来源（未来用户确认公式后）、路径识别、组合效应与成本模型、代表方案方法、GIS展示及异步任务存储。原始材料与历史代码保留。
