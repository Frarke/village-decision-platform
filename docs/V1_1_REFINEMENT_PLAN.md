# V1.1 输入交付与空间结果改进

本轮依据用户对V1交付的反馈执行。沿用已确认四目标、准入阈值和统一评价器，不把地图美化替代空间计算。

## 已确认的缺口

1. 接口字段文档不能替代业务人员的资料清单；要求按生成单元编号提交权重/路径，阻碍一次输入计算。
2. 原模拟网格使用四个矩形高值片区，虽然经过连通运算，仍无法清楚说明治理单元来源。
3. 白色背景地图没有现实地理参照；原始评价、重点区域、生成单元没有可视化追踪。
4. 措施输出只有区域颜色和名称，缺少可供宿主地图直接显示的措施点、符号及解释。
5. 单元级技术配置没有工程量和准确设计线位；不能把新增示意图标说成已完成工程选址或施工设计。

## 本轮范围

- 增加面向集成方的资料清单、文件模板包、输入检查和完整返回示例；保留原JSON接口。
- 输入包分别保存研究范围、上游评价栅格、工程调查表、显式权重与路径的空间记录、预算配置。所有位置以坐标绑定自动生成的单元，不要求预填U01。
- 风险权重数值仍由调用方显式提供；只根据点落入的单元绑定，不新增风险权重生成公式。歧义或缺失须报错，不随意就近匹配。
- 以真实地点建立有CRS的连续模拟评价场，自动生成不规则治理斑块；地点及底图为真实空间参照，范围和风险数据仍标记为模拟。
- 返回源评价面、重点区域、单元及来源片区，地图可逐层核查；风险≥3、距承灾体≤100米等既有规则不变。
- 显示在线真实地图/影像，提供八类措施的工程示意图标、单元详情、方案切换和措施点GeoJSON。图标使用单元内代表点，不表示准确施工位置或数量。
- 继续使用同一评价器/求解器；完成相关测试、完整pytest、语法/导入、服务启动、浏览器关键交互及差异检查。

## 保留的研究边界

仅有易发性和易损性图仍不足以完成现有四目标工程评价：风险/危险性及工程调查条件有各自职责。正式材料未给出完整转换公式时不暗中编造。真实DEM水文路径、地貌坡单元、工程精确线位和工程量计价需后续研究与资料支撑。
