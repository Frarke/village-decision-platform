# 第三版模型定义

## 决策变量

每个治理单元对应一个准入措施组合索引。一个完整个体表示全村各治理单元的措施配置。M01—M08是8类措施编码，Uxx-Mxx是单元—措施准入判定编号。

## 硬约束

- 措施准入、互斥和组合要求；
- 中高风险单元主控工程要求；
- 每单元最大措施数量；
- 全村估算全寿命周期成本预算；
- 高风险单元治理后降雨工况稳定系数下限；
- 高风险单元安全得分下限。

稳定系数是力学底线；安全得分综合稳定性与灾害链控制能力，防止单一分项被平均掩盖。

## 单元评价

治理前降雨工况稳定系数：`FS_before=FS0×K_rain`。

治理后稳定系数：`FS_after=FS0×K_rain+ΔFS_effective`。物源稳定和水控制措施可贡献`ΔFS_effective`；谷坊坝和柔性拦挡结构主要降低输移或冲击后果，不计入物源斜坡稳定性提升。

安全性：`S_safety=0.6S_FS+0.4S_chain`。稳定系数到得分的线性映射、灾害链基础分和措施增量均为待标定参数。

经济性在科技报告生命周期成本等级基础上，加入建设、维护折现、施工组织和地形修正成本。预算使用估算全寿命周期成本；经济性得分以该成本为主导校正，确保增加成本不会无解释地提高经济性。

可持续性由生态恢复、碳排放和工程扰动组成。韧性由功能冗余、恢复难度和关键路径覆盖组成。不治理方案仅具有零新增成本，不因此获得较高可持续性或韧性。

## 区域评价

区域安全性保留“最低安全得分＋风险加权平均”的组合口径；经济性、可持续性和韧性按治理单元风险权重汇总。四项目标均按越大越好进入Pareto判定。

## 空间协同

每条演示风险路径分为物源、输移和承灾体三个环节。各环节分别配置有效措施集合：

- 物源控制：排水、坡面加固、支挡、抗滑等；
- 输移拦截：排水导流、谷坊坝、柔性拦挡等；
- 承灾体防护：挡墙、抗滑桩、柔性拦挡等。

只有措施与环节匹配才计入覆盖。输出完整路径覆盖率、物源控制率、输移拦截率、承灾体防护率、协同贡献、薄弱环节和残余风险。当前这些指标用于结果解释与代表方案复核，没有作为NSGA-II独立优化目标。

## 精确枚举与NSGA-II

精确枚举逐一评价完整组合空间，为当前小案例提供基准。

离散NSGA-II使用约束支配、有限局部修复、非支配排序、拥挤距离、锦标赛选择、离散交叉、变异、随机移民和精英保留。默认60个体×25代。迭代历史记录当代可行个体、当代非支配个体、累计唯一评价数量、实际搜索空间占比、前沿间距离散度和累计档案归一化超体积。

累计档案超体积反映四目标覆盖趋势；它不是解析前沿上的严格收敛证明。工程问题的正确性还要通过精确基准覆盖、硬约束满足、非法组合数量和多随机种子稳定性验证。
