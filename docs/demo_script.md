# 3—5分钟组会演示讲稿

## 0:00—0:35 背景与定位

“中期已经形成了决策框架和方案比选方法，但这些内容仍偏抽象：实际使用时，不清楚从哪一步开始、需要填什么、模型产出什么，也难以与后续正式平台衔接。因此第三版把可调整参数、治理单元、措施筛选、优化计算和结果解释标准化、可视化；核心评价和约束逻辑固定在后端。”

“当前空间单元和风险路径是平台演示数据，不代表现场实测边界；待标定参数和估算成本也不能直接用于施工设计。”

## 0:35—1:20 GIS工作台与地图

“平台现在分为项目总览、数据与单元、智能研判、方案比选、空间协同和成果管理六个模块。中部是村庄级地图，右侧是当前单元详情，左侧只显示当前任务需要的操作。”

现场操作：点击U02，再点击U03。确认右侧名称、类型、坡高、坡度、稳定系数、风险等级、承灾体、准入措施和剔除原因同步变化；确认地图选中边界为橙色。再在表格点击U01，确认地图和详情反向联动。

“这里使用在线街道底图，不把它叫地形底图；断网时可以切换离线坐标网格，本地GeoJSON和模型仍能工作。”

## 1:20—2:05 引导流程与工程准入

“第一次使用选择引导式研判。每一步都有目标、必填项、保存和校验，不满足条件不能下一步；计算成功也不会把前面步骤虚假标成完成。输入变化后旧结果会失效，但只改代表方案偏好不会重跑算法。”

“4个单元和8类措施形成32条准入判定记录。M01—M08只是措施类别编码，每条记录用U01-M01这样的唯一编号。系统给出命中条件、限制条件、准入结论、剔除原因和复核事项。”

## 2:05—2:55 求解与验证

“精确枚举逐一评价全部4,356个组合，适合当前小案例并提供完整基准。默认得到407个可行方案和25个四目标Pareto方案。”

“NSGA-II不遍历全部方案，通过选择、交叉和变异近似搜索。默认60个体、25代；三个随机种子分别评价约45%—47%的空间，均找回全部25个精确Pareto方案，漏解0、被精确集支配比例0。它在当前小案例仍比精确枚举慢，所以这里不夸大算法优势，大规模时才更有价值。”

“算法验证分两层：ZDT1、ZDT2、ZDT3和DTLZ2验证基本机制；精确枚举对照验证离散编码、硬约束和工程评价耦合。两层证据不能互相替代。”

## 2:55—3:45 方案比选与空间协同

“Pareto图明确是四目标解集在某两个指标平面上的投影。代表方案用热力图比较，避免五条雷达曲线叠在一起。页面直接回答推荐哪个方案、成本增量、安全提升、每个单元采用什么措施、哪些参数要复核。”

“空间协同不再是任意措施就算路径被治理。每条路径分物源、输移、承灾体三个环节，只有措施类型匹配才计入覆盖。地图和表格显示完整路径覆盖、物源控制、输移拦截、承灾体防护和未治理薄弱环节。”

“当前协同指标用于结果解释和代表方案复核，还没有作为NSGA-II独立目标，这一点在页面中如实说明。”

## 3:45—4:20 导出与下一步

“最后可导出中文CSV、JSON、完整成果ZIP和HTML科研分析报告。每次运行记录场景编号、时间、方法、随机种子、组合规模、可行数、Pareto数和配置标识。”

“下一步是接入真实村庄治理单元、DEM、房屋道路水系，结合规范、案例、调查和专家评审标定参数，再评估是否把空间协同正式纳入约束或优化目标。”

## 演示前现场检查

1. Windows双击`start_windows.bat`并确认首页打开。
2. 点击U02、U03两个地图单元，确认详情变化和橙色高亮。
3. 点击表格U01，确认反向定位。
4. 快速分析运行精确枚举，确认407/25结果。
5. 切换代表方案，确认地图措施和风险路径同步变化。
6. 下载JSON和HTML报告并打开。
