## 关键逻辑测试

- 下一步只在本步校验通过时前进，纯状态机测试不回到第一步。
- 模块状态与控件状态分离，避免Streamlit同名状态写入异常。
- 输入变化使结果失效；偏好权重变化只重选代表方案。
- 32条准入判定编号唯一；CSV、GeoJSON和拓扑编号一致。
- 删除单元会触发幽灵数据/路径引用错误。
- 谷坊坝与柔性拦挡不直接提升物源稳定系数。
- 不治理方案可持续性和韧性不再虚高。
- 路径只有在措施类型与相应环节匹配时才算有效覆盖。
- 成本增加时经济性不会无解释地上升。
